# Samuel Shang — Writing

A minimal writing portfolio built with Astro. Articles live in `src/content/writing` as Markdown files.

## Add a piece

Duplicate `src/content/writing/sample-piece.md`, rename it with a short URL-friendly filename, update the fields between the `---` lines, and replace the sample text. Set `draft: true` to hide a piece. Categories are stored now and can become visible filters later.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
